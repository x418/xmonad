# Names the river build exports that the X11 build has no counterpart for.
#
# The river API is meant to be a subset of the X11 one, so every entry here is
# an exception that has to earn itself.  These are the cases where river has a
# concept X11 genuinely lacks, and where hiding it would mean a config could
# not express something the compositor supports.
#
# tests/api/check-subset.sh requires this list to match exactly, in both
# directions: a new export fails until it is justified here, and an entry for a
# name river no longer exports fails too.
#
# Note this is measured against the union of the X11 build's own surface *and*
# its Graphics.X11 re-exports.  Window, Rectangle, Event, Position, Dimension,
# KeyMask, KeySym and Button are therefore not listed: they exist in both
# builds, and only move between files, because X11 re-exports them from
# Graphics.X11 while river defines them in XMonad.Core.

# --- The compositor connection ----------------------------------------------

RiverWindow          Everything river has told us about one window, accumulated from its events.
RiverOutput          Likewise for an output.  This is what screens are reconciled from each manage sequence.
RiverSeat            Likewise for a seat.
LayerFocus           Whether a seat's keyboard has gone to a layer surface.
layerHasFocus        Predicate on LayerFocus.  Focus requests must not be made while one holds.
BorderColor          RGBA, as river_window_v1.set_borders takes it.  X11 used a Pixel and a colormap.
noSizeHints          A window that has stated no preferred size.  X11 had no need: XGetWMNormalHints
                   # always returned a SizeHints, with each field independently present or absent.
                   # river reports the whole hint or nothing, so the empty case wants a name.

# --- Driving the manage sequence --------------------------------------------
#
# X11 let a window manager act at any moment.  river permits window management
# state to change only during a manage sequence, so a config acting from a
# timer or a forked thread has to ask for one.  Nothing in the X11 API
# corresponds, because nothing had to.

manageDirty          Ask river to start a manage sequence, because state it cannot observe has changed.

# --- Restart and exit -------------------------------------------------------

RestartRequested     The async exception sendRestart throws into the event loop thread.
setMainThread        Records which thread the event loop runs on, so sendRestart can reach it.
exitSession          Ends the Wayland session.  X11's equivalent was exiting and letting the server notice.

# --- Diagnostics ------------------------------------------------------------

warnUnimplemented    Warns once per process where a name must stay but the behaviour is partial.
                   # Deliberately rare: the rule is that unportable things are not exported at all,
                   # so this is only for shared code that must keep a name it cannot fully honour.
